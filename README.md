# Лабораторная работа: Визуализация алгоритмов сортировки

Приложение на C# WinForms для сравнения алгоритмов сортировки с
пошаговой визуализацией, замером времени и выгрузкой результатов в Excel.

## Возможности

### Ввод данных
- **DataGridView** — таблица с колонками «Значение» и «Отсортировано»
- **Ручной ввод** — числа через пробел (например `5 4 3 2 1`)
- **Генерация** — случайные числа (целые или дробные)
- **Загрузка из Excel (.xlsx)** — читается первый столбец
- **Загрузка из Google Table** — по опубликованной CSV-ссылке

### Алгоритмы сортировки
1. Пузырьковая (`BubbleSort`) — не более n-1 проходов
2. Вставками (`InsertionSort`)
3. Шейкерная (`ShakerSort`) — не более (n-1)/2 проходов
4. Быстрая (`QuickSort`) — рекурсивная
5. BOGO (`BogoSort`) — с лимитом итераций

### Управление
- Направление: **по возрастанию / по убыванию**
- Выбор нескольких алгоритмов через CheckBox
- **Детализация**:
  - включена + ≤ 50 элементов → пошаговая анимация
  - выключена или > 50 элементов → только финальный массив
- **Лимит итераций** — только для BOGO (для остальных не применяется)

### Визуализация
- Гистограмма на панели: синие столбики — элементы, **красный** и
  **оранжевый** — сравниваемые элементы
- Название текущего алгоритма выводится в углу панели

### Результаты
- Таблица «Алгоритм / Время (мс) / Итераций / Статус»
- **Время** — чистое время сортировки, без учёта анимации (формат `F4`)
- **Статус** — «Завершено» или «Лимит итераций» (только для BOGO)

### Сохранение в Excel
- `Файл → Сохранить отсортированное в Excel`
- Отсортированные данные записываются во **2-й столбец**
- Исходный файл можно **перезаписать** или сохранить **как копию**
